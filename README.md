# 🏡 Village Database Manager

**Программа для ведения базы данных домов деревни в двоичном файле**

## 📖 Описание

**Village Database Manager** — это консольное приложение, предназначенное для хранения и управления информацией о домах в деревне. Все данные сохраняются в **двоичном файле**, что обеспечивает компактность хранения и высокую скорость обработки.

Программа идеально подходит для учёта жилого фонда, ведения сельского реестра или личного архива.

---

## ✨ Возможности

- 💾 **Хранение в двоичном файле** — компактно, быстро, надёжно
- 📝 **Полный набор полей для каждого дома:**
  - Материал дома (кирпич, дерево, блок и т.д.)
  - Стоимость
  - Год постройки
  - Этажность
  - ФИО владельца
- 🧭 **Удобное и понятное меню** — вся навигация интуитивна, не требует инструкций
- 🔧 **Лёгкая адаптация под нужды пользователя** — структура данных и меню легко изменяются под конкретные задачи
- ➕ Добавление, просмотр, редактирование и удаление записей
- 🔍 Поиск и фильтрация по любому из полей

---

## 🚀 Быстрый старт

### Требования
- Любая ОС (Windows / Linux / macOS)
- Компилятор C/C++ (или среда, под которую адаптирована программа)

### Запуск
1. Скачайте и распакуйте архив с программой
2. Скомпилируйте исходный код (при необходимости)
3. Запустите исполняемый файл
4. Используйте пункты меню для работы с базой

## 🛠️ Настройка под себя

Программа специально спроектирована так, чтобы её можно было **легко переделать**:

- Хотите добавить поле (например, «Площадь участка»)? — просто расширьте структуру и пункты меню.
- Нужны другие критерии поиска? — измените условия фильтрации.
- Требуется экспорт в текстовый/CSV формат? — добавьте соответствующую функцию.

Благодаря прозрачной структуре кода адаптация занимает минимум времени.
